## Annotations (not data changes)

* `lab2-scripts/00_env.sh`: the `INSTANCE_TYPE` default said "bare metal". The nodes were
  VMs whose HCAs are SR-IOV virtual functions, so the label now says that and a two-line
  comment explains it. Nothing the script measured or ran is affected.
* `nccl/46-nccl-single-algo.txt`: the raw file marks each block with a line
  `== NCCL_ALGO=<name>`, and the curator used to drop those markers. They are kept as
  `# NCCL_ALGO=<name>`. Block order in the raw source is Ring, NVLS, Tree (recorded by the
  markers, not inferred). The `cmd:` header still shows the `<algo>` placeholder.
* `system/08-lspci.txt` is added to the published set (output already filtered to
  Mellanox/NVIDIA lines) as the evidence that the HCAs are virtual functions.

Not present in the source files and so not scrubbed: tokens, keys, account or project IDs.
The public IPs of the VMs appear only in the source tree's own manifest, which is not
published. IB LIDs, QPNs and PSNs are kept (session-scoped, not identifying).

## Curation, not just scrubbing

* nccl-tests files keep headers, result rows and summary lines. About 9 MB of
  `NCCL_DEBUG=INFO` output was dropped; each file ends with a one-line count of the
  transport NCCL reported.
* A few table rows in the 16-rank files were torn by interleaved debug output in the
  raw capture. They are dropped, not repaired. Per file: 41-nccl-single-run1.txt: 2, 41-nccl-single-run2.txt: 2, 41-nccl-single-run3.txt: 2, 42-nccl-multi-run1.txt: 2, 42-nccl-multi-run2.txt: 2, 42-nccl-multi-run3.txt: 2, 43-nccl-inject-one-rail.txt: 1, 44-nccl-inject-ib-disabled.txt: 1, 45-nccl-multi-ring.txt: 1, 47-nccl-multi-net-plugin-none.txt: 1, 48-nccl-multi-net-plugin-none-run2.txt: 1, 48-nccl-multi-net-plugin-none-run3.txt: 1, 49-nccl-multi-allgather.txt: 1, 49-nccl-multi-alltoall.txt: 1.
* Training logs keep header lines and the `RESULT` JSON line.
* `63-train-2node-long-run3.txt`: the corrected copy is used (RESULT valid, hang was at
  teardown). The uncorrected `.node0-copy` is not included.
* Left out on purpose: `nvidia-smi -q` dump, lspci, ibv_devinfo, topology XML, the
  side job run on the same nodes, and everything not about the fabric benchmark.
